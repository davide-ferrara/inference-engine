# Inference Engine for SmolLM2-135M

> [!NOTE]
> This repo is written only by HUMAN and have no AI into it simply to allow me to learn how to make
a basic inference engine. This is very early stage.

## Try it yourself

- Download the model: `https://huggingface.co/HuggingFaceTB/SmolLM2-135M/tree/main`

`bash
git clone https://huggingface.co/HuggingFaceTB/SmolLM2-135M
git lfs install
git lfs pull
`
## Run

```bash
uv run main.py
```
